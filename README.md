# Quantum-Kernel Gait Freezing Prediction App

This project provides a simple desktop application for predicting Parkinson’s freezing-of-gait states from six gait sensor measurements. It uses **traditional quantum machine learning**, not deep learning.

The prediction pipeline is:

> StandardScaler → quantum angle encoding → quantum fidelity kernel → classical SVM

The Tkinter application loads the trained precomputed-kernel SVM and calculates a quantum-kernel row for each new sensor input.

## Features

The application expects the following six input values in exactly this order:

| Feature | Unit |
| --- | --- |
| ACC ML [g] | g |
| ACC AP [g] | g |
| ACC SI [g] | g |
| GYR ML [deg/s] | degrees/second |
| GYR AP [deg/s] | degrees/second |
| GYR SI [deg/s] | degrees/second |

The output is either **No Freezing** or **Freezing Detected**. The application also displays the SVM decision score. This score is not a calibrated probability.

## Project files

The main files are:

| File | Purpose |
| --- | --- |
| `gait_prediction_app.py` | Tkinter desktop prediction application |
| `traditional_quantum_kernel_svm.joblib` | Trained SVM model |
| `traditional_quantum_ml_scaler.joblib` | Fitted feature scaler |
| `quantum_kernel_training_features.npy` | Quantum-transformed training features required by the precomputed SVM |
| `traditional_quantum_ml_metadata.json` | Optional model metadata |

The three model files shown below are required by the application:

```
traditional_quantum_kernel_svm.joblib
traditional_quantum_ml_scaler.joblib
quantum_kernel_training_features.npy
```

The metadata file is optional. If it is absent, the application uses the default six feature names defined in the Python file.

## Requirements

Use Python 3.10 or newer. Install the required packages with:

```bash
pip install pennylane pennylane-lightning scikit-learn pandas numpy joblib
```

Tkinter is included with most standard Python installations. On Ubuntu or Debian, install it with:

```bash
sudo apt-get update
sudo apt-get install python3-tk
```

On Windows and macOS, Tkinter is normally included with the official Python installer.

## Folder setup

Place all required files in one folder:

```
quantum-gait-app/
├── gait_prediction_app.py
├── traditional_quantum_kernel_svm.joblib
├── traditional_quantum_ml_scaler.joblib
├── quantum_kernel_training_features.npy
└── traditional_quantum_ml_metadata.json
```

The model files are generated by the training script after the quantum-kernel SVM has been fitted and saved.

## Running the application

Open a terminal in the project folder and run:

```bash
python gait_prediction_app.py
```

The application window will open. Enter one numeric value for each of the six sensor features and click **Predict Gait State**.

The first prediction may take some time because the application evaluates the quantum kernel between the new sample and every saved quantum training sample. Later predictions also require these kernel evaluations because the SVM was trained with a precomputed kernel.

## Training-model compatibility

The application must use the same preprocessing and quantum kernel as the training script. In particular:

1. The six features must remain in the same order.

1. The same fitted `StandardScaler` must be used.

1. The scaled values must be clipped to the interval `[-pi, pi]`.

1. The same `AngleEmbedding` configuration must be used.

1. The same quantum fidelity kernel must be used.

1. The saved training features must correspond to the samples used to fit the SVM.

Do not replace the scaler or `quantum_kernel_training_features.npy` with unrelated files.

## Input example

A test input may look like this:

```
ACC ML [g]       0.19
ACC AP [g]      -0.51
ACC SI [g]       1.01
GYR ML [deg/s] -10.45
GYR AP [deg/s]  58.09
GYR SI [deg/s]  29.16
```

These values are only an example of the input format. They are not a clinical diagnosis and should not be interpreted as medical advice.

## Important limitation

This application is a research and demonstration tool. It is not a medical device and must not be used by itself to diagnose Parkinson’s disease, freezing of gait, or any other medical condition. Predictions depend on the quality, units, distribution, and sensor placement of the input data.

The output of `SVC.decision_function()` is a signed classification score. It is not a probability. If calibrated probabilities are required, retrain the model with a carefully validated calibration procedure, such as a separately evaluated `CalibratedClassifierCV` workflow.

## Troubleshooting

### Model files are missing

If the application displays a model-loading error, confirm that the three required files are in the same directory as `gait_prediction_app.py`:

```
traditional_quantum_kernel_svm.joblib
traditional_quantum_ml_scaler.joblib
quantum_kernel_training_features.npy
```

### Invalid input

Every field must contain a finite numeric value. Do not enter units, commas, blank spaces, or text such as `N/A`.

### The application is slow

A precomputed quantum kernel requires one quantum-circuit evaluation for each comparison between the new sample and a saved training sample. If the training kernel used 500 samples, one prediction requires approximately 500 kernel evaluations.

For faster demonstration runs, retrain the model with fewer quantum-kernel training samples. This may reduce predictive performance, so evaluate the model again after changing the sample count.

### Device error

The application first tries to use `lightning.qubit` and falls back to `default.qubit` if necessary. The fallback is usually slower but provides a compatible simulator for many installations.

### Feature mismatch

If the application reports a feature or shape mismatch, verify that the saved scaler, SVM, metadata, and NumPy training-feature file were all generated by the same training run.

## Rebuilding the model

The training script should save the artifacts with code similar to:

```python
import joblib
import numpy as np

joblib.dump(svm_model, "traditional_quantum_kernel_svm.joblib")
joblib.dump(scaler, "traditional_quantum_ml_scaler.joblib")
np.save("quantum_kernel_training_features.npy", X_train_q)
```

After retraining, copy the new files into the application folder and restart the Tkinter application.
